# Instrucciones para probar aplicacion

- Tener instalado Postgresql y xampp

- Crear una carpeta en xampp/htdocs y colocar los archivos en esta

- Restorar el backup de la base de datos a una propia

- Rellenar Conexion.php con los datos para la conexion.

- Acceder a través de un navegador a localhost/**(nombre de la carpeta)**
